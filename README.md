# United Electrical Surplus — demo site

A 60 Minute Sites design concept for [unitedelectricalsurplus.com](https://unitedelectricalsurplus.com):
surplus electrical equipment buyer/seller in Lawrenceville & Buford, Georgia.

- Static HTML/CSS/JS, no build dependencies — generated by `_generator/build.py` (Python 3, stdlib only)
- Deploys on Netlify from the repo root (`netlify.toml` included); forms use Netlify Forms
- Brand palette taken from the client's own logo: pine green + gold on ivory
- Photography pulled from the client's current site

See `DEMO-NOTES.md` for the client brief, open items and launch checklist.
